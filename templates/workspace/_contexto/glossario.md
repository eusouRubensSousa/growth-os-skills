# Glossário Accelera 360

> Termos do método. Skills usam estes nomes consistentemente.

---

## Pipeline e tese

| Termo | Significado |
|---|---|
| **Growth AI** | Método A360 — sistema operacional comercial com IA na retaguarda. |
| **Nova Economia** | Tese de fundo — empresas vencedoras na década de 2026+ operam com agentes IA na infraestrutura. |
| **Construa uma vez, instale em N** | Princípio de leverage — 1 sistema replicável por nicho. |
| **Setup + recorrência** | Modelo de monetização — preço de instalação + mensalidade. |
| **IA na retaguarda** | IA é mecanismo invisível que entrega resultado; cliente compra resultado. |

## Ângulos de copy

| Termo | Significado | Quando usar |
|---|---|---|
| **DOR** | Ângulo focado em dor latente do nicho ("Pare de perder R$ X"). | Nicho com dor explícita reconhecida. |
| **OPORTUNIDADE** | Ângulo focado em janela de mercado ("Em 2026 quem não tiver Y some"). | Nicho com tendência clara de adoção. |
| **SISTEMA** | Ângulo focado em escala sem operador ("Sistema operacional pra escalar sem dobrar time"). | Nicho cansado de operação manual. |

## Frameworks de copy (`lp-builder`)

| Termo | Significado |
|---|---|
| **AIDA** | Attention → Interest → Desire → Action — espinha de toda LP. |
| **PAS** | Problem → Agitate → Solve — usado no ângulo DOR. |
| **FAB** | Feature → Advantage → Benefit — converter especificação técnica em benefício. |
| **Hero 5s** | Visitante deve responder "o que é? é pra mim? confio?" em 5s. |
| **Single Conversion Goal** | 1 CTA primário em toda a página, repetido ≥2x. |

## Sistemas estéticos (`lp-builder` + `pitch-deck-builder`)

| Termo | Significado |
|---|---|
| **editorial-serif** | Premium B2B, sóbrio, fonte serif (Instrument Serif). |
| **brutalist-grid** | Disruptor, uppercase, lime ácido, brackets `[ ]`. |
| **mono-tech** | SaaS dev-first, dark, mono font (Geist), dot grid. |
| **Anti-AI** | Conjunto de regras que evita LP/deck cheirar a IA (fontes banidas, gradiente proibido, copy genérica). |

## Vendas (`playbook-vendas`)

| Termo | Significado |
|---|---|
| **D.E.A.L.** | Discovery → Evidence → Action → Lock — espinha do script de venda. |
| **SPIN** | Situation → Problem → Implication → Need-payoff — perguntas de descoberta. |
| **BANT** | Budget / Authority / Need / Timing — qualificação básica. |

## Estrutura do workspace

| Termo | Significado |
|---|---|
| **PARA** | Projects / Areas / Resources / Archive — método de organização (Tiago Forte). |
| **Johnny.Decimal** | Numeração 00-99 hierárquica em pastas — endereço estável. |
| **MoC (Map of Content)** | `_index.md` em cada pasta — hub de navegação. |
| **Lentes** | Arquivos em `_contexto/` carregados em toda sessão antes de qualquer ação. |
| **Modo degradado** | Skill rodou sem pré-requisito — output marcado com `degraded_mode: true`. |
| **Slug** | Identificador kebab-case sem acento de nicho/cliente/oferta. |
| **Ledger** | Tabela em `memory/shared/` com status de todos os nichos/clientes/ofertas. |

## ICP / Persona

| Termo | Significado |
|---|---|
| **ICP** (Ideal Customer Profile) | Perfil empresarial-alvo (setor, tamanho, momento). |
| **Persona** | Indivíduo dentro do ICP (decisor, dor, linguagem). |
| **Trigger** / **Evento gatilho** | Momento que faz o ICP virar prospect ativo. |

## Métricas

| Termo | Significado |
|---|---|
| **CAC** | Custo de Aquisição de Cliente. |
| **LTV** | Lifetime Value — receita total de 1 cliente ao longo do contrato. |
| **MRR** | Monthly Recurring Revenue. |
| **CPL** | Custo Por Lead. |
| **CTR** | Click-Through Rate. |
| **TAM/SAM/SOM** | Total/Serviceable/Obtainable Addressable Market. |

## Termos do método (proprietários)

| Termo | Significado |
|---|---|
| **Mecanismo proprietário** | Nome do sistema que entrega o resultado (ex: "Sistema CARE™"). |
| **Stack de valor** | 5-8 itens que compõem a oferta com valor de mercado individual. |
| **Garantia honesta** | Promessa de resultado em X dias (sem urgência manufaturada). |
| **CTA padrão A360** | Bloco fixo com link site + link aplicação + slogan. |

---

## Quando adicionar termo aqui

Quando uma skill introduz vocabulário novo que outras skills/aluno vão usar repetidamente.
Toda adição deve ter: **termo** + **significado em 1 linha** + **(opcional) quando usar**.
