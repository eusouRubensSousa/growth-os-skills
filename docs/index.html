Skills

Do nicho ao pitch deck em 1 sessão

Cada skill resolve uma etapa. O coordenador encadeia tudo automaticamente.

#0 · Coordenador
/a360-framework-lite

Descreva seu objetivo em linguagem natural. O coordenador analisa, monta o pipeline de skills na ordem certa, valida pré-requisitos, e entrega um sumário consolidado no fim.

#1 · Descoberta
/nicho-explorer

Pesquisa top 10 nichos para IA ou valida 1 nicho específico com veredicto GO/NO-GO (TAM, CAGR, gap competitivo, ICP acessível).

#2 · Mapeamento
/mapear-nicho-lite

Mapeia ICP, dores quantificadas, mecanismo proprietário, oferta base, linguagem do nicho e GTM outline em 1 documento consolidado.

#3 · Prospect
/cliente-radar

Pesquisa um prospect específico: empresa, decisor, concorrentes, top players, gaps e oportunidades de entrada.

#4 · Landing Page
/lp-builder

Gera copy + HTML standalone com frameworks CRO (AIDA, PAS, FAB, Hero 5s). Self-check de 35 itens. 3 sistemas estéticos. Anti-AI audit.

#5 · Go-to-Market
/gtm-architect

Estratégia GTM completa: outbound com sequência de 4 toques e/ou content marketing para o primeiro mês.

#6 · Vendas
/playbook-vendas

Script de diagnóstico 30min (D.E.A.L. lite), 5 objeções com quebras, funil de 5 estágios pronto para usar.

#7 · Reunião
/meeting-prep

Briefing 1-page para uma reunião de vendas específica. Consolida pesquisa do prospect + nicho + deck.

#8 · Pitch Deck
/pitch-deck-builder

Apresentação comercial de 20 slides parametrizada pelo nicho/cliente. Entrega Reveal.js HTML standalone ou PNGs via Gemini.
