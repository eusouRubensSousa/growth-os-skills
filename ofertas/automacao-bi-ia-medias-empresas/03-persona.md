# Persona — Automação + BI + IA para Médias Empresas

> Detalhamento do ICP dentro do nicho. Base para copy do deck/LP e para qualificação em call.

## 1 persona principal (default)

- **Cargo:** COO / Diretor(a) de Operações / Head de Operações (às vezes CFO quando a dor é custo)
- **Receita da empresa:** R$ 5M–80M/ano
- **Tamanho:** 50–500 funcionários
- **Maturidade digital:** baixa a média
- **Contexto:** operação rodando com ERP + planilhas + “ilhas” de dados

## BANT

- **Budget:** setup R$ 25k–60k + recorrência R$ 3k–10k/mês (ajustar pelo recorte)
- **Authority:** decide com sócio/diretor financeiro
- **Need:** reduzir custo operacional + acelerar decisão + eliminar retrabalho/erro
- **Timing:** evento gatilho (auditoria, troca de ERP, crescimento, pressão de margem, demissão chave)

## Linguagem (do nicho)

Usar termos de `nichos/automacao-bi-ia-medias-empresas/05-linguagem.md`.

## Marcadores de fit

- ✓ Já tem dados, mas não confia neles
- ✓ Perde tempo com relatórios manuais
- ✓ Sente pressão por margem / eficiência

## Marcadores de NÃO-fit

- ✗ Quer “IA” como vitrine sem problema claro
- ✗ Não tem dono do processo e não aprova nada
